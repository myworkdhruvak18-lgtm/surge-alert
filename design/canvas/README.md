# Surge Alert design canvas

Source files of the Claude Design canvas (https://claude.ai/artifact/ApKVZT8ajT4iVQM61N4EEu): `canvas.json` is the index (boards, order, journey notes) and each `*.dc.html` is one artboard. Ten journeys: setup, commute ping, pause/mute, normal home, home in the commute window, pickup shift at a house, station and small shop, no-suggestion cases, and the driver rule for alternate pickups (specification only).

The canvas on claude.ai is the live copy; this folder is a snapshot (version 32, 2026-11-21). `docs/prd.md` is the rule book.
